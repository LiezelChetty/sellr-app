# OfferMe brand assets

`offerme-logo.svg` is the original approved artwork supplied for OfferMe. It is used directly in the application through `react-native-svg` and is not redrawn, recoloured, traced, regenerated, or given a tagline.

Expo raster assets are generated by `scripts/generate-brand-assets.mjs`. The script only renders the original SVG proportionally, centres it with clear space on a white square canvas, and does not alter the artwork.
