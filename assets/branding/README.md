# OfferMe brand assets

`offerme-logo.svg` is the unchanged original approved artwork supplied for OfferMe and remains the master source. Runtime UI uses `offerme-logo-runtime.png` through React Native's supported static-image API so Metro never attempts to render an asset module ID as a component.

Expo raster assets are generated by `scripts/generate-brand-assets.mjs`. The script only renders the original SVG proportionally and does not redraw, recolour, trace, or add a tagline. The splash uses the full logo with generous clear space. Square launcher assets use the existing tag portion of the supplied artwork, centred on the required canvas without distortion.

`app.json` configures the OfferMe launcher icon, Android adaptive icon and `expo-splash-screen` asset. Expo Go controls its own blue launch artwork and development builds can also differ from the final launch experience; the configured OfferMe splash should be judged in a preview or production build, while the launcher assets appear in installed development/standalone builds.
